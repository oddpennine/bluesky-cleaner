# Blue Clear · 블루스카이 글 정리

내 블루스카이 글을 최신순으로 불러오고, 날짜·단어로 검색하고, 선택한 글만 백업하거나 영구 삭제하는 정적 웹 도구입니다.

## 사용
앱 비밀번호로 계정을 연결 → 최신 글 불러오기 → 삭제할 글 체크 → 선택 글 삭제 → 확인창에 `삭제` 입력.
샘플 모드는 실제 계정에 영향을 주지 않습니다.
로그인 정보는 브라우저 메모리에만 유지하며, 서버·로컬 스토리지에 저장하지 않습니다.
선택 글 JSON 백업은 기록 보관용이며 원래 글 주소·반응의 자동 복구는 지원하지 않습니다.

## GitHub Pages
Settings → Pages → Deploy from a branch → main / (root) → Save.
별도 빌드나 API 키 설정 없이 index.html, app.js, style.css를 함께 배포합니다.

## 검증 범위
검색·날짜 필터·최신순 요청·페이지 이동·다른 계정/컬렉션 삭제 차단·토큰 갱신·샘플 API 삭제 차단을 모의 테스트했습니다.
실제 계정 연결과 삭제는 별도로 확인해야 합니다.
